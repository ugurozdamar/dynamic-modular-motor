## 📦 Installation & Usage

To test and run the calculation core locally, execute the following commands in your terminal:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com
   ```

2. Navigate into the project directory:
   ```bash
   cd your-repo-name
   ```

3. Initialize the core calculation engine:
   ```bash
   python main.py
   ```
